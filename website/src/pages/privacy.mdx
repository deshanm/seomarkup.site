# Privacy Policy

**Last updated: May 2026**

## Chrome Extension

The SEOMarkup Chrome extension (`app/`) is designed to work entirely within your browser.

- **No data is transmitted.** The extension makes zero outbound network requests.
- **No analytics.** The extension does not collect usage data, page visits, or any information about the websites you inspect.
- **No storage of browsing data.** The only data stored locally is your rating-prompt state (whether you've dismissed the Web Store rating prompt), held in `localStorage` inside the extension popup.
- **Permissions used:** `activeTab` (reads the active tab URL to pre-fill validator links) and `scripting` (injects a function to read `<script type="application/ld+json">` tags and count `itemscope`/`typeof` attributes when you open the popup). No `host_permissions`.

## Website (seomarkup.site)

The marketing site uses:

- **Google Analytics 4** (`G-006FL60JQY`) for page view analytics. [Google's privacy policy](https://policies.google.com/privacy).
- **Tally.so** for the optional feedback form. [Tally's privacy policy](https://tally.so/privacy).
- **Google Fonts** (Poppins) loaded from `fonts.googleapis.com`.

No user accounts, no passwords, no payment data.
